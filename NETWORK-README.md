# Обновление сети v15

## Что работает после замены файлов

- PeerJS загружается с самого сайта, а не с jsDelivr.
- Общая информация лобби передаётся раз в секунду вместо десяти раз в секунду.
- Escape from SVO использует отдельный поток игровых обновлений, поэтому его координаты не зависят от периодичности списка участников.
- У новых игр сетевые снимки объединяются за 50 мс; при загруженном канале сохраняется последний снимок, а игровые команды идут отдельно в ограниченной очереди.
- Таймауты присутствия увеличены с 3–8 до 45 секунд. Короткая просадка связи не должна считаться уходом из игры.
- Добавлены диагностика соединения, измерение RTT и явные слоты игровых комнат.
- Хост отклоняет превышение лимита, включая ботов; переподключение уже сидящего игрока не занимает второе место.

Это снижает избыточный трафик и преждевременные разрывы, но не устраняет блокировку PeerJS/WebRTC на уровне сети.

## Для подключения без PeerJS/WebRTC

В папке server находится собственный WSS relay и инструкция запуска. До размещения сервера и настройки orion-network-config.js этот режим не активен. Все участники должны использовать одинаковый адрес relay. Выбирать сервер нужно по фактической доступности из Белграда и сети друзей, а не по обещанию конкретной страны.

Постоянный матч-сервер, который переживает уход игрового хоста и хранит состояние матча, — отдельный следующий этап. Текущая логика матчей остаётся у хоста; его вкладка должна оставаться активной. Нельзя обещать отсутствие задержек и блокировок, пока не проведён тест из реальных сетей участников.

## Если проблема повторится

Откройте кнопку WebRTC/WSS в левом нижнем углу и сохраните текст диагностики у хоста и отстающего игрока во время проблемы. Она показывает транспорт, RTT, очередь, состояние вкладки и ошибки соединения; игровых данных, IP и секретов в ней нет.
